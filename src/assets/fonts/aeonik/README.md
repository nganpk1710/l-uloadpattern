# Aeonik (chưa kèm theo repo)

Aeonik là font thương mại nên không được commit sẵn. Để toolkit dùng Aeonik cho nhãn và nút điều khiển:

1. Chép file đã có bản quyền vào thư mục này, ví dụ:
   - `Aeonik-Regular.woff2`
   - `Aeonik-Medium.woff2`
   - `Aeonik-Bold.woff2`
2. Khởi động lại `npm run dev` (hoặc build lại).

Không cần sửa code. Tên file được nhận diện theo từ khoá `Thin / Light / Regular / Medium / Semibold / Bold / Black`
và `Italic`. Khi chưa có file, giao diện tạm dùng Helvetica Neue / system sans.
